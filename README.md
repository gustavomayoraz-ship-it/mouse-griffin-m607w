# Mouse Griffin M607W

Programa de escritorio (Python/Tkinter) para configurar los botones del mouse Griffin M607W:
izquierdo, derecho, rueda y los dos laterales X1/X2. Hace clics automáticos por intervalo o por CPS
(máximo 25 CPS), tiene modo manual, congelado de cursor y bandeja del sistema.

## Instalación fácil (sin instalar Python)
**[⬇️ Descargar MouseGriffin-Setup.exe](https://github.com/gustavomayoraz-ship-it/mouse-griffin-m607w/releases/latest)**
y abrilo: baja Python 3.14 y las librerías, instala el programa en *Archivos de programa*, crea los accesos
directos y queda en *Configuración › Aplicaciones* para desinstalarlo desde ahí.
Más detalle en [instalador/_archivos/LEEME.txt](instalador/_archivos/LEEME.txt).

## Uso con Python
1. Windows con Python 3.10 o superior.
2. Ejecutar `mouse.py`. Al iniciar verifica e instala solas las dependencias (ver `requirements.txt`).
3. La X cierra el programa; el botón 📌 lo manda a la bandeja del sistema.
