# Mouse Griffin M607W

Programa de escritorio (Python/Tkinter) para configurar los botones del mouse Griffin M607W:
izquierdo, derecho, rueda y los dos laterales X1/X2. Hace clics automáticos por intervalo o por CPS
(máximo 25 CPS), tiene modo manual, congelado de cursor y bandeja del sistema.

## Uso
1. Instalar Python (el programa se probó con 3.13 y 3.14).
2. Ejecutar `mouse.py`. Al iniciar verifica e instala solas las dependencias
   (ver `requirements.txt`) y abre la aplicación.
3. La X cierra el programa; el botón 📌 lo manda a la bandeja del sistema.

La configuración se guarda en `config.txt`.
